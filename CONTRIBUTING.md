# Contributing

- Keep gameplay changes focused and describe the affected state or object behavior.
- Preserve the C++11 language requirement unless the build configuration is deliberately updated.
- Do not commit generated build directories, binaries, or local score files.
- Test startup, menu navigation, movement, shooting, collisions, and score persistence manually.
- Include screenshots or concise reproduction steps for rendering defects.
- Document any new system dependency or asset path.

Do not change asset licensing or redistribute third-party assets without confirming their permissions.
